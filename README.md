Este proyecto implementa un flujo completo de Ciencia de Datos utilizando Python. El objetivo principal es predecir si un paciente padece o no diabetes a partir de diversas características médicas como los niveles de glucosa en sangre, índice de masa corporal, presión sanguínea, etc. Se ha empleado el dataset clásico de Pima Indians Diabetes, aplicando técnicas de preprocesamiento, imputación de valores perdidos, análisis exploratorio de datos, modelización con algoritmos de machine learning y posterior análisis de los resultados obtenidos.
